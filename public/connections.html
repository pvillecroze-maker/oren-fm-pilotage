Portée des connexions

Les passerelles actuelles fonctionnent avec les applications ouvertes et les données disponibles dans ce navigateur. Elles ne constituent pas une base centrale ni une synchronisation permanente entre téléphone et ordinateur. Les restrictions de stockage du navigateur peuvent bloquer le transfert intégré : utilise alors l’export et l’import JSON.

Les liens vers les actions recherchent le nom du module dans le champ Projet de MÉTIS. Les données de santé restent séparées. Aucune nouvelle autorisation Google ou Apple n’est accordée par cette page.
